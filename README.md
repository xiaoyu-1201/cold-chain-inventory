# 拍照盤點（冷凍材料行）

手機拍貨架 → AI 找出每個商品並框起來 → 跟原圖對照，用 ＋／－ 修正數量 → 存在手機、匯出 Excel。

**網址：** https://xiaoyu-1201.github.io/cold-chain-inventory/

## 第一次用

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 免費建立一把 **Gemini API Key**。
2. 打開上面網址 → 右上齒輪「設定」→ 貼上 Key → 按「儲存並測試」。看到「可以用了！」就好。
3. 加到主畫面，用起來像 App：
   - **iPhone（Safari）**：分享按鈕 → 「加入主畫面」。
   - **Android（Chrome）**：右上選單 → 「安裝應用程式」或「加到主畫面」。

## 怎麼盤點

1. 「＋ 新盤點」→ 填位置（例如「A 貨架第 2 層」）→ 拍照或從相簿選（可以多張）。
2. 「開始辨識」：每張大約 5～15 秒。
3. 結果頁：照片上的框和下面清單同色、同編號。
   - 點清單左邊的編號（或點框），照片會標出是哪幾個。
   - 數量不對就按 ＋／－，或直接打數字。
   - 名稱不對就點品名旁的 ✎：可以改 **品名、品牌、型號、尺寸／規格**（會跳出以前打過的字給你選）。
   - 同一列裡只有幾個不一樣（例如保溫管有一支是 4 分）：先點那一列，再到照片上**點那個框一次**，就能只改那一個，會自動分到對的品項。
   - 標「請確認」的是 AI 不太確定的，要特別看一下。
   - AI 沒找到的，按右上「＋ 手動新增」。
4. 「匯出」：下載 Excel（CSV）、分享到 LINE／Email，或複製成文字。

## 怎麼拍比較準

- 一次拍一層貨架，正面拍、不要太斜。
- 光線夠、不要反光；標籤朝外最好。
- 疊在一起、被擋住的，結果出來再修正。

## 店內品項清單

設定裡可以改「店內品項清單」（一行一種，括號寫規格或別名）。AI 會照清單的名稱寫，修正時也會跳出來給你選。

## 樣品照（長得很像、只差尺寸的商品）

例如 4 種銅管三通混在一起，AI 只看一張照片，常常全部歸成「三通」。解法是給它看「正確答案」：

1. 盤點結果裡，先點那個框、再點一次，改成正確的名稱和尺寸（例如「銅管三通／4分 等徑」）。
2. 按「儲存，並存成樣品照」：App 會把那個框切下來存起來。
3. 每一種都存一張。之後每次辨識，App 會把樣品照（最多 30 張，新的優先）一起送給 AI 比對，AI 就會照樣品的名稱和尺寸寫。

也可以在「設定 → 樣品照」直接拍一張。樣品照只存在這支手機，辨識時跟盤點照片一起送到 Google Gemini。

還是分不開時，可以到「設定 → 辨識模型 → 重新挑選」改用 Pro：看得比較細，但比較慢、免費額度比 Flash 少很多。

## 結果頁：只看要確認的

- 最上面的總結卡：共幾件、幾種、**有幾個要確認**。
- App 會自動標出可能不一樣的框（橘色虛線＋「?」）：AI 說跟同一種的不一樣、大小跟同一種的其他個差很多、AI 沒把握。
- 按「N 個要確認」只看這幾個：一樣就按「✓ 一樣」，不一樣就選它是哪一種。看完就不會再標。
- 同一個東西被框兩次，會自動合併（數量不會多算）。
- 漏掉的：按「＋ 漏掉的，點照片補一個」，在照片上點那一個。
- 東西擠在一起看不清楚：按照片右下角 ⤢ 全螢幕放大，框照樣可以點。

## 相似品再比對、速度與穩定

- **相似品再比對**：同一種名稱有 2 個以上、框的大小差很多時，App 會在背景把這些框用「同一個比例」切成小圖並排給 AI，一個一個比粗細和接口，再分組。結果會先出來，比對好了自動更新。也可以點品項的 ✎ →「再比對一次」。
- **快**：找東西、畫框時把 AI 的「思考」調到最少；多張照片一次送兩張。
- **雙保險**：主模型 15 秒還沒回，就同時請比較快的模型一起做，誰先好就用誰，另一個馬上取消。單次等超過 40 秒就自動換模型。
- **網路斷一下會自動重送**；辨識時會讓螢幕保持亮著（螢幕暗掉或切到別的 App，手機會把連線斷掉）。

## 隱私與資料

- API Key 只存在這支手機的瀏覽器裡，不會上傳到任何地方。
- 照片只會送到 Google Gemini 分析。
- 盤點紀錄（含照片）只存在這支手機；換手機或清除瀏覽器資料就會不見，要留底請用「匯出」。

## 為什麼比之前的版本好

| 之前的問題 | 現在 |
|---|---|
| 寫死模型名稱，模型下架就壞 | 自動列出可用的模型，挑最新、穩定、快的；下架自動換 |
| 分析很慢 | 照片先縮到 1600px 再上傳；2.5 Flash 關掉「思考」，快很多 |
| Google 忙線（503）就失敗 | 自動重試 3 次（2、4、8 秒），還是忙就換下一個模型；失敗會顯示錯誤代碼 |
| AI 回傳的文字硬轉格式，常失敗 | 用結構化輸出（JSON Schema），格式固定 |
| 沒有原圖對照 | 每個商品都框起來，框和清單同色同編號 |
| 無法存檔 | 存在手機（IndexedDB），可匯出 CSV、分享、複製 |

## 技術

純 HTML／CSS／JavaScript，沒有套件、不用建置。檔案：`index.html`、`app.js`、`styles.css`、`sw.js`（離線快取）、`manifest.webmanifest`。
